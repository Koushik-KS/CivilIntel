# CivilIntel

CivilIntel is an AI-powered Development Intelligence Platform that helps governments analyze citizen development requests and identify priority infrastructure needs.

## Features
- Multilingual citizen requests
- Text and messaging-based issue reporting
- AI-based category and priority analysis
- Citizen request management
- Demand hotspot identification
- Project recommendations using regional data
- Digital Public Infrastructure impact tracking

## Tech Stack
- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios
